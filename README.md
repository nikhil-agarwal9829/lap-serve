# LapServe

Premium doorstep laptop repair platform — India's most trusted repair experience.

**Tagline:** WE BUILD TRUST

## Tech Stack

- React 19 + TypeScript + Vite
- Tailwind CSS v4
- Framer Motion, GSAP, Three.js (@react-three/fiber)
- Radix UI, Lenis smooth scroll, React Query

## Getting Started

```bash
cd lapserve
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173)

## Build

```bash
npm run build
npm run preview
```

## Pages

- Home (Hero + ARIA, Trusted By, How It Works, Why LapServe)
- Services (mega menu + category pages)
- Brands (grid + brand detail with models)
- Booking, Pricing, Locations, FAQ, Testimonials, Contact, About

## Features

- **A.R.I.A.** — Three.js retro monitor assistant with eye tracking, blink, and state animations
- Sticky glass navbar with services mega menu
- WhatsApp floating CTA + ARIA chatbot panel
- Lenis smooth scroll, GSAP timeline animations
- SEO meta tags + Organization schema markup
